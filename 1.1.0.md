# 1.1.0

> #### **Release Highlights**
>
> * Added Azure CSP
> * Added My Page
> * Improved snapshot-based recovery feature

## New Features

#### Added Azure CSP

All features provided in OwlDB 1.0.0 can be used on Azure.

{% hint style="info" %}
**Note** The archive recovery feature is not supported on Azure.
{% endhint %}

#### Dashboard

**Top N Chart**

A TopN chart has been added to the dashboard. You can check information for up to the top 5 instances with high CPU usage, Memory usage, and Session load.

#### Estimated Amount

When infrastructure resource configurations such as provisioning and spec changes are added/changed, you can check the estimated amount based on the database.

{% hint style="info" %}
**Note**

The actual amount may vary depending on various factors such as the region or the user's workload.
{% endhint %}

#### My Page

**Account Management**

A feature has been added to check the information of the currently used account and change the password.

**Usage Management**

A feature has been added to query the license fee for each database managed in OwlDB.

* In the Usage Status menu, you can check this month's database usage status.
* In the Usage History menu, you can check the monthly database usage history for up to the last 5 years.

{% hint style="info" %}
**Note**

Infrastructure resource costs are excluded.
{% endhint %}

#### Notification

**Email Sending**

An email sending feature has been added. You can also check the various notifications provided by OwlDB via email.

***

## **Changes**

### Feature Improvements

#### Filter Settings

The issue where the database/instance selected in the management and monitoring menus was reset when the screen was refreshed has been improved.

#### Snapshot-based recovery feature

The operation method has been improved to increase the intuitiveness of the recovery feature.

* If you perform recovery without selecting a snapshot, the point in time for recovery is entered separately as before, and recovery is performed to that point in time.
* If you perform recovery after selecting a snapshot, recovery proceeds immediately to the point in time of the snapshot selected by the user.

### Usability Improvements

#### Menu Composition

The overall menu composition of OwlDB has been changed. It has been changed from the previous method of using a 1-depth side menu to a method of using a 2-depth side menu.

#### List Query Method

Components that were provided in an infinite scroll manner have been changed to a pagination manner.
