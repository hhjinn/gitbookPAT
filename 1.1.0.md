# New Features

### Added Azure CSP

All features provided in OwlDB 1.0.0 can be used on Azure.

{% hint style="info" %}
**Note**
The archive recovery feature is not supported on Azure.
{% endhint %}

### Dashboard

**Top N Chart**

A TopN chart has been added to the dashboard. You can check information on up to the top 5 instances with high CPU usage, Memory usage, and Session load.



### Estimated Cost

When infrastructure resource configurations such as provisioning and specification changes are added/modified, you can check the estimated cost based on the database.

{% hint style="info" %}
**Note**

The actual cost may vary depending on various factors such as the region or the user's workload.
{% endhint %}



### My Page

**Account Management**

A feature has been added to check the information of the currently used account and change the password.

**Usage Management**

A feature has been added to query the license fee for each database managed by OwlDB.

- In the Usage Status menu, you can check this month's database usage status.
- In the Usage History menu, you can check the monthly database usage history for up to the last 5 years.

{% hint style="info" %}
**Note**

Infrastructure resource costs are excluded.
{% endhint %}



### Notifications

**Email Delivery**

An email delivery feature has been added. You can also check various notifications provided by OwlDB via email.

# **Changes**



## Feature Improvements

### Filter Settings

Improved the phenomenon where the database/instance selected in the Management and Monitoring menus was reset when the screen was refreshed.

### Snapshot-based recovery feature

The operation method has been improved to enhance the intuitiveness of the recovery feature.

- If you perform recovery without selecting a snapshot, the recovery point is separately entered as before and recovery is performed to that point.
- If you perform recovery after selecting a snapshot, recovery proceeds immediately to the point of the snapshot selected by the user.



## Usability Improvements

### Menu Structure

The overall menu structure of OwlDB has been changed. It has been changed from using a 1-depth side menu to using a 2-depth side menu.

### List Query Method

Components that were provided in an infinite scroll method have been changed to a pagination method.
