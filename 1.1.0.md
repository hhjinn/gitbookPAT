# New Features

### Azure CSP Added

All features provided in OwlDB 1.0.0 are available on Azure.

{% hint style="info" %}
**Note**
The archive recovery feature is not supported on Azure.
{% endhint %}

### Dashboard

**Top N Chart**

A TopN chart has been added to the dashboard. You can view information on up to the top 5 instances with the highest CPU usage, Memory usage, and Session load.



### Estimated Cost

When infrastructure resource configurations are added or changed, such as provisioning and spec changes, you can view the estimated cost on a per-database basis.

{% hint style="info" %}
**Note**

The actual cost may vary depending on various factors such as the region and the user's workload.
{% endhint %}



### My Page

**Account Management**

A feature has been added to view the information of the currently used account and change the password.

**Usage Management**

A feature has been added to look up license fees for each database managed in OwlDB.

- In the Usage Status menu, you can view this month's database usage status.
- In the Usage History menu, you can view monthly database usage history for up to the last 5 years.

{% hint style="info" %}
**Note**

Infrastructure resource costs are excluded.
{% endhint %}



### Notifications

**Email Delivery**

An email delivery feature has been added. You can also receive the various notifications provided by OwlDB via email.

# **Changes**



## Feature Improvements

### Filter Settings

Improved the issue where the database/instance selected in the Management and Monitoring menus was reset when the screen was refreshed.

### Snapshot-Based Recovery Feature

The behavior has been improved to make the recovery feature more intuitive.

- If you perform recovery without selecting a snapshot, the recovery point is entered separately as before, and recovery is performed to that point.
- If you perform recovery after selecting a snapshot, recovery proceeds immediately to the point in time of the snapshot selected by the user.



## Convenience Improvements

### Menu Structure

The overall menu structure of OwlDB has been changed. It has changed from using a 1-depth side menu to using a 2-depth side menu.

### List View Method

Components that were provided with an infinite scroll method have been changed to a pagination method.
