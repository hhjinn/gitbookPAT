# 데이터 스페이스

데이터 공간 관리 페이지에서는 DB 서비스의 데이터 저장 단위를 조회하고 관리합니다.

접속한 DB 서비스의 엔진 유형에 따라 화면 구성과 제공 기능이 달라집니다. 

Tibero 엔진에서는 데이터 저장의 논리적 단위인 테이블스페이스와 실제 데이터를 기록하는 데이터 파일을 조회·생성·수정·삭제할 수 있습니다. 

OpenSQL 엔진에서는 데이터베이스 목록 조회, 생성, 삭제를 지원하며, 개별 데이터베이스를 선택하면 Tuple Health·활성 세션 수 등의 상태 지표를 포함한 상세 정보를 조회합니다.

{% hint style="info" %}
**참고**\
OpenSQL 데이터베이스 관리 기능은 Azure 환경에서만 지원합니다. AWS 환경에서는 OpenSQL 엔진을 사용하는 경우 데이터 공간 관리 기능을 사용할 수 없습니다.
{% endhint %}
