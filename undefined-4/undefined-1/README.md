The Data Space page retrieves and manages the data storage units of the DB service.

The screen layout and available features vary depending on the engine type of the connected DB service.

{% tabs %}
{% tab title="Tibero" %}
You can retrieve, create, modify, and delete tablespaces, which are the logical units of data storage, and data files, which record the actual data.
{% endtab %}
{% tab title="OpenSQL" %}
It supports retrieving, creating, and deleting the database list, and when you select an individual database, it retrieves detailed information including status indicators such as Tuple Health and the number of active sessions.
{% endtab %}
{% endtabs %}
