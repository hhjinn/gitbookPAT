The Data Space page allows you to view and manage the data storage units of a DB service.

The screen layout and available features vary depending on the engine type of the connected DB service.

{% tabs %}
{% tab title="Tibero" %}
You can view, create, modify, and delete tablespaces, which are the logical units of data storage, and data files, which store the actual data.
{% endtab %}
{% tab title="OpenSQL" %}
It supports viewing, creating, and deleting the database list, and selecting an individual database displays detailed information including status metrics such as Tuple Health and the number of active sessions.
{% endtab %}
{% endtabs %}
