# 백업 설정

백업 설정 페이지에서는 자동 백업 스케줄러를 구성하고 운영 상태를 확인합니다.

# 백업 설정

자동 백업의 사용 여부, 실행 주기, 보존 기간, 시작 시간을 설정하며, 스케줄러의 최근 실행 결과·7일 성공률·연속 실패 횟수와 30일 실행 이력 차트를 통해 백업 안정성을 점검합니다.

**관리 > 백업 설정** 메뉴를 클릭하면 현재 설정된 자동 백업 구성 정보를 확인합니다.

{% hint style="info" %}
**참고**

Cloud 환경에서는 CSP Snapshot 기능을 사용해 Full/Incremental 구분 없이 단일 자동 백업으로 관리합니다.
{% endhint %}

1. **관리 > 백업 설정**을 클릭합니다.
2. **수정**을 클릭합니다.
3. 자동 백업 토글을 **켜짐**으로 설정합니다.
4. 자동 백업 주기, 보존 기간, 시작 시간을 입력합니다.
5. **저장**을 클릭합니다.

페이지에는 다음 항목이 표시됩니다.

| 항목 | 설명 | 입력 규칙 |
| --- | --- | --- |
| 자동 백업 | 자동 백업 활성화 여부 (켜짐/꺼짐) | 기본값: 꺼짐 |
| 자동 백업 주기 | 자동 백업이 실행되는 주기 | - 시간마다: 1~23<br>- 일마다: 1~7 |
| 보존 기간 | 생성된 백업 이미지를 보존하는 기간 | - 시간마다: 1~23<br>- 일마다: 1~35 |
| 시작 시간 | 자동 백업이 처음 시작되는 일시 | 현재보다 과거 일시는 선택 불가 |
| 최근 백업 일자 | 가장 최근에 자동 백업이 완료된 일시 | 표시 전용 |
| 다음 백업 일자 | 다음 자동 백업 예정 일시 | 표시 전용 |

{% hint style="warning" %}
**주의**

자동 백업을 켜짐으로 설정하면 저장 주기와 보존 기간에 따라 저장 용량이 늘어나며, 별도 요금이 발생합니다.
{% endhint %}

# 백업 스케줄러 운영 상태

백업 설정 페이지 하단의 **백업 스케줄러 운영 상태** 섹션에서 자동 백업의 최근 실행 이력과 안정성 지표를 확인합니다. 자동 백업이 꺼진 상태에서도 마지막 실행 정보가 표시됩니다.

| 항목 | 설명 | 미설정 시 표시 |
| --- | --- | --- |
| 최근 실행 결과 | 가장 최근에 완료된 자동 백업의 성공/실패 여부 | `-` |
| 최근 7일 성공률 | 최근 7일 이내 완료된 자동 백업의 성공 비율 (예: 90% (9/10)) | `-` |
| 연속 실패 횟수 | 가장 최근 완료 건부터 연속으로 실패한 횟수 (모두 성공인 경우 0회) | `-` |
| 최근 30일 실행 결과 차트 | 최근 30일간 일자별 자동 백업 성공/실패 건수를 누적 막대 차트로 표시 | No Data 상태 표시 |

차트에서 성공과 실패는 색상으로 구분됩니다. 막대 위에 마우스를 올리면 해당 일자의 자동 백업 성공·실패 건수 상세 정보를 확인합니다.

1. **관리 > 백업 설정**을 클릭합니다.
2. 페이지 하단의 **백업 스케줄러 운영 상태** 섹션에서 최근 실행 결과, 최근 7일 성공률, 연속 실패 횟수를 확인합니다.
3. **최근 30일 실행 결과 차트**에서 막대 위에 마우스를 올려 일자별 상세 실행 결과를 확인합니다.
