When a new version of OwlDB is released, you can apply the latest version directly from the console.

1. **At the top of the dashboard**a sky-blue update notification banner appears.
2. Within the notification banner **Update** Clicking the button proceeds with the update.

{% hint style="info" %}
**Note**

Service updates do not affect the databases in operation.
{% endhint %}

{% hint style="info" %}
**Note**

If you have closed the notification banner, at the bottom of the detailed menu area **info icon**Click to proceed with the service update.
{% endhint %}
