## Root initial login <a href="#root-first-login" id="root-first-login"></a>

Once OwlDB deployment is complete, the Root account information is sent to the email address entered during stack creation.

| Item | Initial value |
| --- | --- |
| ID | admin or user-entered value |
| Password | Temporary password |

1. Go to the connection URL stated in the email.
2. Enter the Root account and temporary password received in the email.
3. **Login** Click the button.
4. For security on first login, **Change Password** You are automatically redirected to the page.
5. Enter a new password.
6. Change the password.
7. Log in again with the changed password.

{% hint style="warning" %}
**Caution**

- Be sure to change your password after the first login.
- You cannot navigate to other pages until you change your password.
{% endhint %}

## Login <a href="#login" id="login"></a>

**Login** Enter your account information on the page to connect to OwlDB.

1. **Login** Enter your ID and password on the page.
2. **Login** Click the button.
3. Once authentication is complete, **Dashboard** You are redirected to the page.

{% hint style="info" %}
**Note**

If you do not have a Member account, **Login** On the page, **Request Account Creation** You can click the button to request account creation. For more details, refer to Request Account Creation.
{% endhint %}

## Find ID <a href="#find-id" id="find-id"></a>

If you forget your ID, you can verify it through your registered email address.

{% hint style="info" %}
**Note**

The Find ID feature is only available in the Cloud environment.
{% endhint %}

1. **Login** On the page, **Find ID**Click it.
2. Enter your registered email address.
3. **Send Email**Click it.
4. Once the entered email address is verified, an ID notification email is sent.
5. **Log In**Click **Login** You are redirected to the page.

### Email Verification Criteria by Account <a href="#undefined" id="undefined"></a>

| Account | Email to enter |
| --- | --- |
| Root | The email address entered when subscribing to OwlDB |
| Member | The email address registered to the account |

{% hint style="info" %}
**Note**

If the entered email address does not match the registered information, the ID cannot be found.
{% endhint %}

## ID Notification Email <a href="#id-notification-email" id="id-notification-email"></a>

Once email verification is complete, an ID notification email is sent to the registered email address.

The email includes the following information.

- ID
- OwlDB **Login** Page Shortcut

After receiving the email, **Go to OwlDB**Click **Login** Go to the page and log in with the provided ID.

### If you did not receive the email <a href="#undefined-1" id="undefined-1"></a>

If the ID notification email did not arrive, **Resend Email**Click to send it again.

{% hint style="info" %}
**Note**

Emails can be resent up to 5 times within 10 minutes. If you exceed the resend limit, you must try again after a certain period of time.
{% endhint %}

## Reset Password <a href="#reset-password" id="reset-password"></a>

If you forget your password, you can verify your registered account information, receive a temporary password, and change it to a new password.

{% hint style="info" %}
**Note**

The Reset Password feature is only available in the Cloud environment.
{% endhint %}

### Issue Temporary Password <a href="#undefined-2" id="undefined-2"></a>

1. **Login** On the page, **Reset Password**Click.
2. Enter your ID and registered email address.
3. **Send Email**Click it.
4. Once the entered account information is verified, a temporary password is sent to the registered email address.
5. **Log In**Click **Login** You are redirected to the page.

{% hint style="info" %}
**Note**

If the entered ID and email address do not match the registered information, a temporary password cannot be issued.
{% endhint %}

## Log in with the temporary password <a href="#temporary-password-login" id="temporary-password-login"></a>

1. In the email, **Temporary password**Check.
2. **Login** Enter your ID and temporary password on the page.
3. **Login**Click.
4. **Reset Password** You are automatically redirected to the page.

{% hint style="warning" %}
**Caution**

When logging in with a temporary password, you cannot use other pages until you change your password.
{% endhint %}

## Change Password <a href="#change-password" id="change-password"></a>

1. Enter a new password.
2. Re-enter the password to confirm it.
3. **Change Password**Click it.
4. Once the password change is complete, **Login** You are redirected to the page.
5. Log in again with the changed password.

{% hint style="info" %}
**Note**

You cannot use a password that is identical to your existing password.
{% endhint %}
