## Root First Login <a href="#root-first-login" id="root-first-login"></a>

The initial ID and password for the Root account are as follows.

| Item | Initial Value |
| --- | --- |
| ID | admin |
| Password | admin |

1. Enter the initial ID and password.
2. **Login** Click the button.
3. For security purposes, upon first login **Change Password** You are automatically redirected to the page.
4. Enter and change the new password.
5. Log in again with the changed password.

{% hint style="warning" %}
**Caution**

Be sure to change the password after the first login.

You cannot move to other pages until the password is changed.
{% endhint %}

## Login <a href="#login" id="login"></a>

1. Enter the ID and password on the login page.
2. **Login** Click the button.
3. Once authentication is complete, you are redirected to the dashboard page.

**Note**

## ID and Password Information <a href="#id-password-guide" id="id-password-guide"></a>

In the On-Premise environment, the ID lookup and password reset features are not provided. If you have forgotten your ID or need to reset your password, you must contact the Root (administrator) for assistance.

{% hint style="info" %}
**Note**

The ID lookup and password reset features via email authentication are provided only in the Cloud environment.
{% endhint %}

### If You Have Forgotten Your Account Information <a href="#undefined" id="undefined"></a>

- If you have forgotten your ID: Contact the Root (administrator) to verify your registered ID.
- If you have forgotten your password: Request a password reset from the Root (administrator).

## Member Password Reset <a href="#member-reset-password" id="member-reset-password"></a>

Root **My Page > Account Management** On the page, you can verify the ID of a Member account and reset the password directly.

1. Log in with the administrator (Root) account.
2. **My Page > Account Management** Move to the page.
3. Select the Member account whose password you want to reset.
4. **Edit** Click the button.
5. Automatically generate a temporary password or enter a password to modify it.
6. Deliver the reset password to the relevant Member.

The Member logs in again on the login page using the password received from the Root.

{% hint style="info" %}
**Note**

For detailed account management methods, **Account Management**.
{% endhint %}
