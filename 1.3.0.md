# New Features

### On-Premise Environment Support

Newly supports the use of OwlDB in On-Premise environments.
Database construction and operation management are possible even in the customer's internal infrastructure environment.



### Database Registration and Installation

**Database Registration**

You can register and manage an existing Tibero already in operation with OwlDB.
Registered databases can use the same operational features such as status inquiry, parameter management, and backup/recovery in the OwlDB console.

**Database Installation**

Supports an automatic installation feature to newly build Tibero in an On-Premise environment.
When you enter the configuration information required during the installation process, everything from database creation to initial setup is performed at once, allowing you to quickly configure an operating environment based on a standardized architecture.



### Change Detection

Through the change detection feature, you can check database status changes and spec changes that occurred outside of OwlDB, and reflect the changed configuration information in OwlDB.



### Account and Permission Management

**Account Management**

Added a feature to create and manage user accounts.

You can set the access and usage permissions for databases managed in OwlDB for each account.

**Permission Management**

You can control feature access based on the Root and Member permission system.
Depending on the permission, the ability to perform major tasks such as database creation and deletion is restricted.

- Root: Administrator permission that can perform database operation and major management tasks
- Member: General user permission that can inquire assigned databases and use limited operational features



### Failback

Added a Failback feature that can restore the operating environment switched after a Failover to its original configuration.
After failover, the Primary and Standby roles are reorganized, allowing the service operating configuration to be restored to a normal state.

# **Changes**

## Feature Improvements

### Backup/Recovery

**RMGR-based Backup Support**

Supports the RMGR-based backup feature in On-Premise environments.

- Cloud Environment: CSP Snapshot-based
- On-Premise Environment: RMGR-based

By applying a backup method appropriate for the environment, backup management suited to the database operating environment is possible.

**Backup Scheduler**

In the backup scheduler, you can configure Full Backup and Incremental Backup separately.

- You can configure a backup policy suited to the operating environment by setting the execution cycle and retention period for each backup type.
- Full Backup: Performs a backup based on the entire data.
- Incremental Backup: Performs a backup based on data changed since the previous backup.

**Backup Chain Management**

In the backup list, you can view the relationship between Full Backup and Incremental Backup on a chain basis. Incremental Backup is managed in association with its base Full Backup.



## Removed Features

### Backup Scheduler

**Removal of the 'Auto Retention' Setting Feature**

The auto retention setting feature has been removed to prevent backup files from accumulating unnecessarily.
