> ### **Release Highlights**
> 
> - Disaster Recovery (DR) Configuration Support and Auto Failover Feature Provided
> - Storage Auto Scaling Feature Added
> - OwlDB Service Automatic Update
> - Dashboard Status Value Improvement and Card View Added

# New Features

### General

**Dark Mode Support**

Dark mode can now be used according to user preferences, providing visual comfort.

**HTTPS Applied**

The security of the service has been strengthened by applying the HTTPS protocol and a domain name.

### 

### **OwlDB Service Update**

A feature has been added to update OwlDB immediately without rebuilding when a new version is released, enhancing service continuity.



### Database Creation

**Rocky Subscription Verification (AWS Only)**

&nbsp;A procedure has been added to verify Rocky subscription status in advance before entering the database creation page.

**'Disaster Recovery (hereinafter DR) Configuration' Step Added**

- In addition to the existing Single and TAC configurations, DR configuration is newly supported.
- You can select whether to use Auto Failover and the automation level.

**'Availability Zone (hereinafter AZ) Configuration' Step Added**

- You can directly select the AZ of the database node to be created.
- When using DR configuration, high availability is supported through a Multi-AZ configuration.

**Storage Auto Scaling Settings**

A feature has been added to automatically expand storage when storage usage reaches a threshold, supporting stable service operation.

- You can select whether to use the Storage Auto Scaling feature.
- When storage usage reaches the configured threshold, storage is automatically expanded by 10% from the existing capacity.
- To prevent excessive expansion and cost, you can set a maximum storage capacity limit.

** OS Timezone Settings**

A feature has been added to set the OS timezone where the database is installed. (This affects SQL results such as sysdate and systimestamp.)



### Spec Change

**TAC Scale In/Out**

When using a TAC configuration, a feature has been added to manually scale computing resources up/down.

**DR Configuration Change**

- DR configuration can be added to Single and TAC configurations.
- DR configuration can be changed/removed in Single+DR and TAC+DR configurations.

# **Changes**

## Feature Improvements

### Dashboard

**Status Value Improvement**

The existing 3 states (Operation Status, Instance Status, Cluster Tool Status) have been redefined into 2 status values (Health, Status) to provide users with more intuitive status information.

**List View Improvement**

The list view has been improved to support Depth, allowing detailed lookup of not only database information but also instance information.



### Backup/Recovery

**Automatic Reflection of Data File Changes**

When a Data File is added between the backup point and the recovery point, the feature has been improved to automatically create the Data File during the recovery process.

**Expanded Snapshot Recovery Options**

In addition to the PITR (Point In Time Recovery) option, a complete recovery option has been added for snapshot recovery.



## Convenience Improvements

### General

**Action Button Adjustment**

Among the previously listed buttons, those with similar properties have been grouped together to improve readability.

**Table Column Adjustment**

A feature has been added to change the order of columns displayed in the table or to enable/disable them.



### Dashboard

**Card View Added**

A card view type that allows you to concisely check only important information has been added, increasing the speed of grasping information.



### Database Creation

**Change of BYOL License Upload Location**

The upload location for the BYOL license file has been changed from the 'Engine Options' step to the 'Configuration Review' step, so that after completing all settings, you can accurately apply the license suited to the final configuration following an intuitive flow.

**Expanded Maximum vCPU Options**

The EC2/VM type options have been expanded to allow selection of up to 96 vCPUs.

**Automatic Calculation of Redo Log Volume Size**

The Redo Log Volume Size has been changed to use an automatically calculated value instead of being set directly by the user.

**Change of Listener Port Input Location**

The Listener Port input item from the removed 'Network Configuration' step has been changed to be entered in the additional configuration of the 'Database Configuration' step, simplifying the procedure.

**Simplification of DB User Creation**

Instead of creating a new DBA user as before, the procedure has been simplified so that only the password for the SYS user needs to be entered.



## Removal Information

### Database Creation

**Removal of the 'Network Configuration' Step**

As VPC (VNet) and Subnet information were deemed unnecessary, the 'Network Configuration' step has been removed.
