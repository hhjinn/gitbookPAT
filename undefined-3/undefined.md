**관리 > Overview** 또는 **대시보드**에서 DB Service를 선택한 후 **작업** 버튼을 클릭하여 아래 기능들을 수행할 수 있습니다.

{% hint style="info" %}
**참고**

DB Service 중지는 최대 7일(168시간)까지 가능합니다. 7일 이내에 직접 시작하지 않으면 168시간이 경과한 후 다음 정각에 자동으로 시작합니다.
{% endhint %}

1. **작업** 버튼을 클릭합니다.
2. **중지** 또는 **시작** 버튼을 클릭합니다.

---

# DB Service 삭제

1. **작업** 버튼을 클릭합니다.
2. **삭제** 버튼을 클릭합니다.
3. 입력창에 DB Service Name을 입력합니다.
4. **확인** 버튼을 클릭합니다.

{% hint style="warning" %}
**주의**

DB Service를 중지해도 프로비저닝된 스토리지에 대한 비용은 부과됩니다. 지정된 보존 기간 내의 수동 스냅샷 및 자동 백업을 포함하여 백업 스토리지에 대한 요금도 부과됩니다.
{% endhint %}

---

# DB Service 삭제

1. **작업** 버튼을 클릭합니다.
2. **삭제** 버튼을 클릭합니다.
3. 입력창에 DB Service Name을 입력합니다.
4. **확인** 버튼을 클릭합니다.

{% hint style="warning" %}
**주의**

삭제한 DB Service는 다시 복구할 수 없으며 모든 데이터가 완전히 삭제됩니다.
{% endhint %}

---

# [역할 전환](#switchover) (Switchover)

DR 구성 시에만 활성화되는 기능입니다.

1. **작업** 버튼을 클릭합니다.
2. **역할 전환** 버튼을 클릭합니다.
3. 비밀번호를 입력합니다.
4. **확인** 버튼을 클릭합니다.
5. 새로운 Primary가 될 Standby 데이터베이스를 선택합니다.
6. 변경 사유를 입력합니다.
7. **확인** 버튼을 클릭합니다.

{% hint style="info" %}
**참고**

드롭다운 목록에는 상태가 `Available`인 Standby 데이터베이스만 표시됩니다.
{% endhint %}
