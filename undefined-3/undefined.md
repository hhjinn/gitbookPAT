**관리 > Oveview** 또는 **대시보드**에서 데이터베이스를 선택한 후 **작업** 버튼을 클릭하여 아래 기능들을 수행할 수 있습니다.

# 데이터베이스 중지 및 시작

**중지** 버튼을 클릭하면 데이터베이스를 일시적으로 중지할 수 있으며, 중지된 데이터베이스는 **시작** 버튼을 클릭하여 다시 시작할 수 있습니다.

1. **작업** 버튼을 클릭합니다.
2. **중지** 또는 **시작** 버튼을 클릭합니다.

---

# **데이터베이스 삭제**

1. **작업** 버튼을 클릭합니다.
2. **삭제** 버튼을 클릭합니다.
3. 입력창에 DB Service Name을 입력합니다.
4. **확인** 버튼을 클릭합니다.

{% hint style="warning" %}
**주의**

삭제한 데이터베이스는 다시 복구할 수 없으며 모든 데이터가 완전히 삭제됩니다.
{% endhint %}

---

# 등록 해제

등록 DB 에서만 활성화 되는 기능입니다.

1. **작업** 버튼을 클릭합니다.
2. **등록 해제** 버튼을 클릭합니다.
3. 입력창에 DB Service Name을 입력합니다.
4. **확인** 버튼을 클릭합니다.

{% hint style="warning" %}
**주의**

**참고** 등록 해제된 DB Service는 목록에서 조회할 수 없으며, 재등록 시 다시 조회할 수 있습니다.
{% endhint %}

---

# [**역할 전환**](#switchover) (Switchover)

DR 구성 시 활성화되는 기능입니다.

1. **역할 전환** 버튼을 클릭합니다.
2. 비밀번호를 입력하고 **확인** 버튼을 클릭합니다.
3. 새로운 Primary가 될 Standby 데이터베이스를 선택하고 변경 사유를 입력합니다.
4. **확인** 버튼을 클릭합니다.

{% hint style="info" %}
**참고**

드롭다운 목록에는 상태가 `Available`인 Standby 데이터베이스만 표시됩니다.
{% endhint %}

---

# Failback

TAC-DR 구성 시에만 활성화되는 기능입니다.

1. **[Failback]** 버튼을 클릭합니다.
2. 비밀번호를 입력하고 **[확인]** 버튼을 클릭합니다.
