# Syslog

Syslog 페이지에서는 DB 인스턴스에서 발생하는 이벤트, 경고, 오류 등의 시스템 로그를 조회합니다.

{% hint style="info" %}
**참고**

- Tibero는 DB 탭만 제공하며, DB 탭에서 원문 로그를 확인합니다.
- OpenSQL은 DB 탭 외에 Component 탭을 통해 OpenHA·OpenProxy·OpenBackup 컴포넌트의 로그 파일 목록 조회 및 다운로드를 지원합니다. Component 탭은 Azure 환경의 OpenSQL에서만 표시됩니다.
{% endhint %}

# DB Syslog 조회

**모니터링 > 로그 모니터링 > Syslog** 페이지에서는 시스템에서 발생하는 이벤트와 프로세스 로그를 확인합니다. 페이지 진입 시 DB 탭이 기본으로 활성화되며, 로그는 줄(라인) 단위로 표시됩니다. 각 행 좌측에 행 번호가 표시되고, 본문 영역에는 로그 원문이 그대로 나타납니다.

{% hint style="info" %}
**참고**

DB Syslog는 최근 7일 이내의 데이터만 조회할 수 있습니다. 7일을 초과한 로그는 표시되지 않습니다.
{% endhint %}

{% hint style="warning" %}
**주의**

DB Service가 `Terminating` 상태이면 Syslog를 조회할 수 없습니다. 화면 상단에 안내 배너가 표시됩니다.
{% endhint %}

1. **모니터링 > 로그 모니터링 > Syslog**를 클릭합니다.
2. 조회 기간 드롭다운에서 원하는 기간을 선택합니다.
3. **[OpenSQL]** 로그 레벨 드롭다운에서 확인할 로그 유형을 선택합니다.
4. 필요에 따라 검색어를 입력합니다.
5. 필요에 따라 정렬 순서를 변경합니다.
6. 목록에서 로그 내용을 확인합니다.
7. 최신 데이터로 갱신하려면 새로고침 아이콘을 클릭합니다.

# 컴포넌트 로그 목록 조회

{% hint style="info" %}
**참고**

컴포넌트 로그 조회는 **Azure 환경의 OpenSQL**에서만 사용할 수 있습니다. AWS 환경 및 Tibero에서는 [Component] 탭이 표시되지 않습니다.
{% endhint %}

Azure의 OpenSQL DB Service에서는 Syslog 페이지의 [Component] 탭에서 OpenHA, OpenProxy, OpenBackup 컴포넌트의 로그 파일 목록을 조회합니다.

| 항목 | 설명 |
| --- | --- |
| 컴포넌트명 | 로그 파일이 속한 컴포넌트(OpenHA / OpenProxy / OpenBackup) |
| 파일명 | 컴포넌트에서 생성된 원본 로그 파일명 (예: `patroni.log`) |
| 마지막 업데이트 일시 | 로그 파일의 최종 수정 시각 (yyyy.mm.dd HH:1f1f2-1f1f2:ss) |
| 파일 크기(MB) | 로그 파일의 크기 |

{% hint style="info" %}
**참고**

컴포넌트별 로그 파일 구성은 다음과 같습니다.

- **OpenBackup**: DB Service당 로그 파일 1개
- **OpenProxy**: OpenProxy가 설치된 인스턴스당 로그 파일 1개 (미설치 인스턴스의 파일은 목록에 표시되지 않음)
- **OpenHA**: 인스턴스당 로그 파일 1개
{% endhint %}

컴포넌트명 필터(전체 / OpenHA / OpenProxy / OpenBackup)를 사용해 특정 컴포넌트의 파일만 표시할 수 있습니다. 열 헤더를 클릭하면 정렬 기준을 변경할 수 있으며, 기본값은 마지막 업데이트 일시 최신순입니다.

1. **모니터링 > 로그 모니터링 > Syslog**를 클릭합니다.
2. **[Component]** 탭을 클릭합니다.
3. 컴포넌트명 필터를 선택해 목록을 좁힙니다.
4. 목록에서 로그 파일의 이름, 업데이트 일시, 크기를 확인합니다.

# 컴포넌트 로그 다운로드

{% hint style="info" %}
**참고**

컴포넌트 로그 다운로드는 **Azure 환경의 OpenSQL**에서만 사용할 수 있습니다.
{% endhint %}

[Component] 탭에서 로그 파일을 선택한 뒤 [다운로드] 버튼을 클릭하면 확인 모달이 나타납니다. 선택한 파일 수에 따라 모달 내용과 다운로드 방식이 달라집니다.

| 선택 파일 수 | 다운로드 방식 | 모달 표시 정보 |
| --- | --- | --- |
| 1개 | 원본 파일명 그대로 단일 파일 다운로드 | - 컴포넌트<br>- 파일명<br>- 마지막 업데이트 일시<br>- 파일 크기 |
| 2개 이상 | `component_syslog_yymmdd.zip` 형식의 ZIP 파일로 다운로드 | - 선택 파일 수<br>- 다운로드 파일명 |

ZIP 파일명의 `yymmdd`는 다운로드를 요청한 날짜를 의미합니다.

다운로드가 완료되면 결과를 토스트 메시지로 안내합니다. 성공 시 "Syslog 파일이 다운로드되었습니다.", 실패 시 "Syslog 파일 다운로드에 실패했습니다. 다시 시도해 주세요." 토스트가 표시됩니다.

1. **모니터링 > 로그 모니터링 > Syslog**를 클릭합니다.
2. **[Component]** 탭을 클릭합니다.
3. 다운로드할 로그 파일을 하나 이상 선택합니다.
4. **[다운로드]** 버튼을 클릭합니다.
5. 모달에서 파일 정보를 확인하고 **[다운로드]** 버튼을 클릭합니다.
