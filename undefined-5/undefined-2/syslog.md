The Syslog page displays system logs such as events, warnings, and errors that occur in the DB instance. For Tibero, you can view the raw logs in the DB tab, while OpenSQL supports viewing and downloading the log file list for the OpenHA, OpenProxy, and OpenBackup components through the Component tab in addition to the DB tab.

## Viewing DB Syslog

**Monitoring > Log Monitoring > Syslog** This page displays system logs such as events, warnings, and errors that occur in the system. When you enter the page, the DB tab is activated by default, and logs are displayed line by line. A row number is shown on the left of each row, and the raw log content appears as-is in the body area.

{% hint style="info" %}
**Note**

DB Syslog can only be queried for data within the last 7 days. Logs older than 7 days are not displayed.
{% endhint %}

{% hint style="info" %}
**Note**

The OpenSQL DB Service added through registration uses the `owl.env`'s `DB_LOG_DIR`If you did not specify it as the OpenSQL DB log folder, DB Syslog may not function properly. For details, please refer to the [registration manual](../../undefined/undefined-1/opensql/db-1.md).
{% endhint %}

{% hint style="warning" %}
**Caution**

If the DB Service is in a `Terminating` state, Syslog cannot be queried. An informational banner is displayed at the top of the screen.
{% endhint %}

1. **Monitoring > Log Monitoring > Syslog**Click.
2. Select the desired period from the query period dropdown.
3. **[OpenSQL]** Select the log type to view from the log level dropdown.
4. Enter a search term as needed.
5. Change the sort order as needed.
6. Check the log content in the list.
7. To refresh with the latest data, click the refresh icon.

## Viewing the Component Log List

{% hint style="info" %}
**Note**

Component log viewing is available only for **OpenSQL**. In Tibero, the **Component** tab is not displayed.
{% endhint %}

In OpenSQL DB Service, you can view the log file list for the OpenHA, OpenProxy, and OpenBackup components in the **Component** tab of the Syslog page.

| Item | Description |
| --- | --- |
| Component Name | The component to which the log file belongs (OpenHA / OpenProxy / OpenBackup) |
| File Name | The original log file name generated by the component (e.g., `patroni.log`) |
| Last Updated | The last modified time of the log file (yyyy.mm.dd HH:mm:ss) |
| File Size (MB) | The size of the log file |

{% hint style="info" %}
**Note**

The log file composition for each component is as follows.

- **OpenBackup**: One log file is created per DB Service.
- **OpenProxy**: One log file is created for each instance where OpenProxy is installed, and files for instances without it installed are not displayed in the list.
- **OpenHA**: One log file is created per instance.
{% endhint %}

You can use the component name filter (All / OpenHA / OpenProxy / OpenBackup) to display only files of a specific component. Clicking a column header lets you change the sort criteria, and the default is by last updated in descending order.

1. **Monitoring > Log Monitoring > Syslog**Click.
2. **Component** Click the tab.
3. Select the component name filter to narrow the list.
4. Check the name, update time, and size of the log file in the list.

## Downloading Component Logs

{% hint style="info" %}
**Note**

Component log downloading is available only for **OpenSQL**.
{% endhint %}

**Component** When you select a log file in the tab and click the **Download** button, a confirmation modal appears. The modal content and download method vary depending on the number of selected files.

<table data-full-width="true"><thead><tr><th>Number of Selected Files</th><th>Download method</th><th>Modal display information</th></tr></thead><tbody><tr><td>1 file</td><td>Downloads a single file with the original file name as-is</td><td><ul><li>Component Name</li><li>File Name</li><li>Last Updated</li><li>File Size (MB)</li></ul></td></tr><tr><td>2 or more files</td><td><code>component_syslog_yymmdd.zip</code> Downloads as a ZIP file in the format</td><td><ul><li>Number of Selected Files</li><li>Download File Name</li></ul></td></tr></tbody></table>

The ZIP filename's `yymmdd`refers to the date the download was requested.

When the download completes, the result is displayed as a toast message.

- **Success**: Displays "Syslog file has been downloaded."
- **Failure**: Displays "Failed to download the Syslog file. Please try again."

1. **Monitoring > Log Monitoring > Syslog**Click.
2. **Component** Click the tab.
3. Select one or more log files to download.
4. **Download** Click the button.
5. Check the file information in the modal and **Download** Click the button.
