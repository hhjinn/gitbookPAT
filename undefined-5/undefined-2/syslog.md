On the Syslog page, you can view system logs such as events, warnings, and errors occurring in the DB instance. For Tibero, you can check the raw logs in the DB tab, and for OpenSQL, in addition to the DB tab, the Component tab supports viewing and downloading the log file lists of the OpenHA, OpenProxy, and OpenBackup components.

## View DB Syslog

**Monitoring > Log Monitoring > Syslog** On this page, you can check system logs such as events, warnings, and errors that occur in the system. When you enter the page, the DB tab is activated by default, and logs are displayed line by line. A row number is shown on the left of each row, and the original log text appears as-is in the main area.

{% hint style="info" %}
**Note**

DB Syslog can only query data from within the last 7 days. Logs older than 7 days are not displayed.
{% endhint %}

{% hint style="info" %}
**Note**

For an OpenSQL DB Service added through registration, the one used during initial registration `owl.env`of `DB_LOG_DIR`If you did not designate as the OpenSQL DB log folder, DB Syslog may not work properly. For more details, [registration manual](../../undefined/undefined-1/opensql/db-1.md)please refer to.
{% endhint %}

{% hint style="warning" %}
**Caution**

If the DB Service is in `Terminating` state, Syslog cannot be queried. A notice banner is displayed at the top of the screen.
{% endhint %}

1. **Monitoring > Log Monitoring > Syslog**Click.
2. Select the desired period from the query period dropdown.
3. **[OpenSQL]** Select the log type to check from the log level dropdown.
4. Enter a search term as needed.
5. Change the sort order as needed.
6. Check the log content in the list.
7. To refresh with the latest data, click the refresh icon.

## Querying the component log list

{% hint style="info" %}
**Note**

Component log query is available only in **OpenSQL**. In Tibero, the **Component** tab is not displayed.
{% endhint %}

In OpenSQL DB Service, on the **Component** tab of the Syslog page, you can query the list of log files for the OpenHA, OpenProxy, and OpenBackup components.

| Item | Description |
| --- | --- |
| Component name | The component to which the log file belongs (OpenHA / OpenProxy / OpenBackup) |
| File name | The original log file name generated by the component (e.g., `patroni.log`) |
| Last update date and time | The last modified time of the log file (yyyy.mm.dd HH\:mm:ss) |
| File size (MB) | The size of the log file |

{% hint style="info" %}
**Note**

The log file composition for each component is as follows.

- **OpenBackup**: One log file is generated per DB Service.
- **OpenProxy**: One log file is generated for each instance where OpenProxy is installed, and files for instances without OpenProxy installed are not displayed in the list.
- **OpenHA**: One log file is generated per instance.
{% endhint %}

Using the component name filter (All / OpenHA / OpenProxy / OpenBackup), you can display only the files of a specific component. Clicking a column header changes the sort criteria, and the default is the most recent last update date and time.

1. **Monitoring > Log Monitoring > Syslog**Click.
2. **Component** Click the tab.
3. Select the component name filter to narrow down the list.
4. Check the name, update date and time, and size of the log file in the list.

## Downloading component logs

{% hint style="info" %}
**Note**

For component log download, **OpenSQL**only this can be used.
{% endhint %}

**Component** after selecting a log file on the tab, clicking the **Download** button displays a confirmation modal. The modal content and download method differ depending on the number of selected files.

<table><thead><tr><th>Number of selected files</th><th>Download method</th><th>Modal display information</th></tr></thead><tbody><tr><td>1 file</td><td>Single file download with the original file name as-is</td><td><ul><li>Component name</li><li>File name</li><li>Last update date and time</li><li>File size (MB)</li></ul></td></tr><tr><td>2 or more</td><td><code>component_syslog_yymmdd.zip</code> Download as a ZIP file in the format</td><td><ul><li>Number of selected files</li><li>Download file name</li></ul></td></tr></tbody></table>

In the ZIP file name, `yymmdd`refers to the date the download was requested.

When the download is complete, the result is shown via a toast message.

- **Success**: Displays "The Syslog file has been downloaded."
- **Failure**: Displays "Failed to download the Syslog file. Please try again."

1. **Monitoring > Log Monitoring > Syslog**Click.
2. **Component** Click the tab.
3. Select one or more log files to download.
4. **Download** Click the button.
5. Check the file information in the modal and **Download** Click the button.
