**Bootlog** 페이지에서 DB 부팅 절차와 관련된 상태 및 오류 정보를 확인하고 문제 발생 원인을 진단합니다. boot·down 이벤트별로 로그를 조회하고, 각 메시지를 클릭하면 우측 사이드 패널에서 전체 상세 로그를 확인합니다.

# Bootlog 조회

Bootlog 화면에는 선택한 DB 인스턴스의 부팅·종료 이벤트 이력이 표시됩니다. 이벤트·모드·상태 필터와 메시지 검색으로 원하는 로그를 좁힌 뒤, 메시지 링크를 클릭하면 우측 사이드 패널에서 전체 상세 로그를 확인합니다.

{% hint style="warning" %}
**주의**

인스턴스가 `Terminating` 상태일 때는 Bootlog를 조회할 수 없습니다.
{% endhint %}

**조회 기간**

화면 상단에서 조회할 기간을 설정합니다.

| 옵션 | 설명 |
| --- | --- |
| 최근 1일 / 3일 / 7일 / 1개월 | 현재 기준 해당 기간 이내 데이터를 조회합니다. |
| 직접 입력 | 시작일과 종료일을 직접 지정합니다. |

1. **모니터링 > 로그 모니터링 > Bootlog**를 클릭합니다.
2. 조회할 기간을 선택합니다.
3. 이벤트, 모드, 상태 필터를 설정해 조회 범위를 좁힙니다.
4. 특정 메시지를 검색하려면 검색창에 키워드를 입력합니다.
5. 확인할 로그의 **메시지** 링크를 클릭합니다.
6. 화면 우측 사이드 패널에서 해당 로그의 상세 내용을 확인합니다.
