# 계정 생성 요청

OwlDB 계정이 없는 사용자는 로그인 페이지에서 계정 생성을 직접 요청할 수 있습니다.

1. 로그인 페이지에서 **계정 생성 요청** 버튼을 클릭합니다.
2. 아래 정보를 입력합니다.
   * 아이디
   * 이름
   * 비밀번호
   * 비밀번호 확인
   * 이메일
3. **요청** 버튼을 클릭합니다.
4. 계정 생성 요청 모달에서 **확인** 버튼을 클릭하면 **로그인** 페이지로 이동합니다.


## 계정 승인

{% hint style="info" %}
**참고**\
관리자가 계정 생성을 승인하면 계정이 활성화됩니다.
{% endhint %}
