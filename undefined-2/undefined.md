## Root 최초 로그인

Root 계정의 초기 아이디와 비밀번호는 아래와 같습니다.

| 항목 | 초기값 |
| --- | --- |
| 아이디 | admin |
| 비밀번호 | admin |

1. 초기 아이디와 비밀번호를 입력합니다.
2. **로그인** 버튼을 클릭합니다.
3. 최초 로그인 시 보안을 위해 **비밀번호 변경** 페이지로 자동 이동합니다.
4. 새로운 비밀번호를 입력하고 변경합니다.
5. 변경한 비밀번호로 다시 로그인합니다.

{% hint style="warning" %}
**주의**

최초 로그인 후 반드시 비밀번호를 변경합니다.

비밀번호를 변경하기 전까지는 다른 페이지로 이동할 수 없습니다.
{% endhint %}

---

## 로그인

1. 로그인 페이지에서 아이디와 비밀번호를 입력합니다.
2. **로그인** 버튼을 클릭합니다.
3. 인증이 완료되면 대시보드 페이지로 이동합니다.

{% hint style="info" %}
**참고**

Member 계정이 없는 경우, 로그인 페이지에서 **계정 생성 요청** 버튼을 클릭하여 계정 생성을 요청할 수 있습니다. 자세한 내용은 **계정 생성 요청**을 참고합니다.
{% endhint %}

---

## 아이디·비밀번호 안내

On-Premise 환경에서는 아이디 찾기와 비밀번호 재설정 기능을 제공하지 않습니다. 아이디를 잊어버렸거나 비밀번호를 재설정해야 하는 경우, Root(관리자)에게 문의하여 처리해야 합니다.

{% hint style="info" %}
**참고**

이메일 인증을 통한 아이디 찾기와 비밀번호 재설정 기능은 Cloud 환경에서만 제공합니다.
{% endhint %}

### 계정 정보를 잊어버린 경우

- 아이디를 잊어버린 경우 : Root(관리자)에게 문의하여 등록된 아이디를 확인합니다.
- 비밀번호를 잊어버린 경우 : Root(관리자)에게 비밀번호 재설정을 요청합니다.

## Member 비밀번호 재설정

Root는 **마이페이지 > 계정 관리** 페이지에서 Member 계정의 아이디를 확인하고 비밀번호를 직접 재설정할 수 있습니다.

1. 관리자(Root) 계정으로 로그인합니다.
2. **마이페이지 > 계정 관리** 페이지로 이동합니다.
3. 비밀번호를 재설정할 Member 계정을 선택합니다.
4. **수정** 버튼을 클릭합니다.
5. 임시 비밀번호를 자동 생성하거나 비밀번호를 입력하여 수정합니다.
6. 재설정된 비밀번호를 해당 Member에게 전달합니다.

Member는 Root로부터 전달 받은 비밀번호로 로그인 페이지에서 다시 로그인합니다.

{% hint style="info" %}
**참고**

자세한 계정 관리 방법은 **계정 관리**를 참고합니다.
{% endhint %}
