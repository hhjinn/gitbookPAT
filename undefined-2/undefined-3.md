# 서비스 업데이트

새로운 버전의 OwlDB가 출시되면, 콘솔에서 바로 최신 버전을 적용할 수 있습니다.

* **대시보드 상단**에 하늘색 업데이트 알림 배너가 나타납니다.
* 알림 배너 내 **업데이트 하기** 버튼을 클릭하면 업데이트가 진행됩니다.
* 서비스  업데이트는 운영 중인 데이터베이스에 영향을 미치지 않습니다.

{% hint style="info" %} **참고** 참고

알림  배너를 닫은경우, 상세 메뉴 영역 하단의 **info 아이콘**을 클릭하여 서비스 업데이트를 진행할 수 있습니다. {% endhint %}
