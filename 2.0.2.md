#### Bug Fixes <a href="#undefined-1" id="undefined-1"></a>

**Agent**

**Fixed an issue where OPENSQL\_HOME was not registered in the agent configuration file**

Fixed an issue where, in the agent configuration file `owlagent.env`, if only the `[pg]` section was entered without entering the `[barman]` section, the empty value that followed overwrote the preceding value, so `OPENSQL_HOME` was not registered in `.bash_profile`.

* The duplicated `USERNAME` and `OPENSQL_HOME` have been consolidated into the `[pg, barman common]` common section and are entered only once.
* Changed so that lines with empty values are not applied when loading the configuration file.

***

### **Items to Check When Upgrading** <a href="#undefined-2" id="undefined-2"></a>

* If `OPENSQL_HOME` was not registered because the `[barman]` section was not entered in a previous agent version, you must update the agent to 2.0.2 and then reapply `owlagent.env`.
