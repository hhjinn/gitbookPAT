# 2.0.2

> **Release Highlights**
>
> * Fix OPENSQL\_HOME not being registered in the agent configuration file

### **Changes** <a href="#undefined" id="undefined"></a>

#### Bug Fixes <a href="#undefined-1" id="undefined-1"></a>

**Azure**

**Fix public IP creation failure when newly deploying CP**

Fixed an issue where deployment failed because the public IP was not created when newly deploying CP on Azure.

* This occurred because creation of Basic tier public IPs is blocked on Azure.
* Changed to create public IPs as Standard tier.
* Already deployed CPs are not affected.

**Agent**

**Fix OPENSQL\_HOME not being registered in the agent configuration file**

Fixed an issue where, in the agent configuration file `owlagent.env`, when only the `[pg]` section was entered without the `[barman]` section, the empty value that followed overwrote the preceding value, so that `OPENSQL_HOME` was not registered in `.bash_profile`.

* The duplicated `USERNAME` and `OPENSQL_HOME` have been consolidated into the `[pg, barman common]` common section and are entered only once.
* Changed so that lines with empty values are not applied when loading the configuration file.

***

### **Notes for Upgrading** <a href="#undefined-2" id="undefined-2"></a>

* If `OPENSQL_HOME` was not registered because the `[barman]` section was not entered in a previous agent version, you must update the agent to 2.0.2 and then reapply `owlagent.env`.
