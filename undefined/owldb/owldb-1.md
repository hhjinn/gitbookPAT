OwlDB를 설치하기 전에 서버가 갖춰야 할 시스템·네트워크 요구사항을 확인하고 사전 환경을 준비합니다.

---

## 시스템 요구사항

OwlDB를 설치할 서버에 아래 요구사항이 충족되어 있는지 확인합니다.

### 1. 하드웨어 요구사항

| 항목 | 최소 사양 | 비고 |
| --- | --- | --- |
| CPU | 2 Core 이상 | - |
| Memory | 8GB 이상 | - |
| Disk | 50GB 이상 | 로그, 백업 파일 저장 공간 포함 |

### 2. 소프트웨어 요구사항

OwlDB는 Docker 기반으로 동작하므로, 설치 전 반드시 아래 소프트웨어들이 설치되어 있어야 합니다.

**Docker**

| 항목 | 요구사항 |
| --- | --- |
| Docker | 29.3.1 이상 |
| Docker Compose | V2 (2.x) 이상 |

### 3. 디스크 구성

OwlDB 설치를 위해 최소 50GB 이상의 디스크 공간이 필요하며, 아래와 같이 용도별로 구분하여 구성할 것을 권장합니다.

| 영역 | 용도 | 권장 크기 |
| --- | --- | --- |
| 설치 경로 | OwlDB 바이너리 및 설정 파일 | 10GB |
| 데이터 경로 | 메타데이터 저장소 | 20GB |
| 로그 경로 | OwlDB 운영 로그 | 10GB |
| 백업 경로 | 백업 파일 저장소 | 10GB |

---

## 네트워크 요구사항

OwlDB 서버는 사용자(웹 브라우저)와 각 데이터베이스 서버 양쪽과 통신합니다. 아래 포트 구성과 통신 허용 설정을 사전에 완료합니다.

### 1. OwlDB 서버 포트 구성

OwlDB 서버에서 아래 포트가 열려 있어야 합니다.

| 포트 | 용도 | 방향 |
| --- | --- | --- |
| 80/tcp<br>(포트 변경 가능) | 사용자 웹 브라우저 접속 | 사용자 → OwlDB 서버 인바운드 허용 |

### 2. 방화벽 설정

위 포트 구성에 따라 OwlDB 서버와 데이터베이스 서버 간 방화벽 허용 설정이 필요합니다. 고객 환경의 방화벽 정책에 맞게 인바운드·아웃바운드 규칙을 설정합니다.
