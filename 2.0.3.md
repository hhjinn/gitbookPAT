# 2.0.3

> **Release Highlights**
>
> * Fixed all nodes being marked abnormal when an etcd member fails
> * Fixed some parameters not being applied when a parameter template is applied

### **Changes** <a href="#undefined" id="undefined"></a>

#### Bug Fixes <a href="#undefined-1" id="undefined-1"></a>

**OpenSQL**

**Fixed all nodes being marked abnormal when an etcd member fails**

Fixed an issue where, in an HA configuration, if a problem occurred with one etcd member or an old unused address remained in the node settings, the etcd of all nodes was marked abnormal and the DB appeared as Down.

* After the fix, the determination is based on the member list, so only the node of the member with the problem is marked abnormal.

**Tibero**

**Fixed some parameters not being applied when a parameter template is applied**

Fixed an issue where hidden parameters included in the template were not applied when applying the OLTP or OLAP parameter templates in Tibero.

* Also fixed an issue where hidden parameters changed by a template were not reverted to their original values when restoring a set.
* The items displayed on the parameter lookup screen remain the same as before.

#### Feature Improvements <a href="#undefined-2" id="undefined-2"></a>

**OpenSQL**

**Added quorum etcd check for registered DBs**

Extended the check so that the quorum (witness) etcd status of externally registered OpenSQL DBs, which was not previously checked, is now checked together based on the member list.

***

### **Items to Check When Upgrading** <a href="#undefined-3" id="undefined-3"></a>

* If you applied the Tibero OLTP or OLAP parameter template in a previous version, you must reapply the template after upgrading to 2.0.3 for the previously unapplied parameters to take effect.
