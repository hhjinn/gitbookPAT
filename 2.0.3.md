# 2.0.3

> **Release Highlights**
>
> * Fix incorrect display of all nodes as abnormal when an etcd member fails
> * Fix some parameters not being applied when applying a parameter template

### **Changes** <a href="#undefined" id="undefined"></a>

#### Bug Fixes <a href="#undefined-1" id="undefined-1"></a>

**OpenSQL**

**Fix incorrect display of all nodes as abnormal when an etcd member fails**

Fixed an issue where, in an HA configuration, if one etcd member had a problem or an unused old address remained in the node settings, etcd on all nodes was marked as abnormal and the DB appeared as Down.

* After the fix, the determination is based on the member list, so only the node of the affected member is marked as abnormal.

**Tibero**

**Fix some parameters not being applied when applying a parameter template**

Fixed an issue where hidden parameters included in the OLTP and OLAP parameter templates were not reflected when applying the templates in Tibero.

* Also fixed an issue where hidden parameters changed by a template were not reverted to their original values during set restoration.
* The items displayed on the parameter lookup screen remain the same as before.

#### Improvements <a href="#undefined-2" id="undefined-2"></a>

**OpenSQL**

**Added quorum etcd check for registered DBs**

Extended the check so that the quorum (witness) etcd status of externally registered OpenSQL DBs, which was not being checked, is now checked together based on the member list.

***

### **Notes for Upgrading** <a href="#undefined-3" id="undefined-3"></a>

* If you applied the Tibero OLTP or OLAP parameter template in a previous version, you must reapply the template after upgrading to 2.0.3 for the previously unreflected parameters to take effect.
