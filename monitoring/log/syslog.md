On the Syslog page, you can look up system logs such as events, warnings, and errors that occur in the DB instance. Tibero lets you view the raw logs in the DB tab, while OpenSQL supports viewing and downloading the log file lists of the OpenHA, OpenProxy, and OpenBackup components through the Component tab in addition to the DB tab.

## DB Syslog Lookup <a href="#view-db-syslog" id="view-db-syslog"></a>

**On the Monitoring > Log Monitoring > Syslog** page, you can check system logs such as events, warnings, and errors that occur in the system. When you enter the page, the DB tab is activated by default, and logs are displayed line by line. A row number is shown on the left side of each row, and the raw log appears as is in the body area.

{% hint style="info" %}
**Note**

DB Syslog can only query data from within the last 7 days. Logs older than 7 days are not displayed.
{% endhint %}

{% hint style="info" %}
**Note**

For an OpenSQL DB Service added through registration, the `owl.env`of `DB_LOG_DIR`used during initial registration — if it is not designated as the OpenSQL DB log folder — may cause DB Syslog to not work properly. For details, please refer to the [registration manual](../../installation-guide/database-server/opensql/register-db-prerequisites.md).
{% endhint %}

{% hint style="warning" %}
**Caution**

If the DB Service is in the `Terminating` state, Syslog cannot be looked up. An informational banner is displayed at the top of the screen.
{% endhint %}

1. **On the Monitoring > Log Monitoring > Syslog**Click.
2. Select the desired period from the query period dropdown.
3. **[OpenSQL]** Select the log type to check from the log level dropdown.
4. Enter a search term as needed.
5. Change the sort order as needed.
6. Check the log contents in the list.
7. To refresh with the latest data, click the refresh icon.

## Component Log List Lookup <a href="#component-log-list" id="component-log-list"></a>

{% hint style="info" %}
**Note**

Component log lookup is available only in **OpenSQL**. In Tibero, the **Component** tab is not displayed.
{% endhint %}

In an OpenSQL DB Service, you can look up the log file lists of the OpenHA, OpenProxy, and OpenBackup components in the **Component** tab of the Syslog page.

| Item | Description |
| --- | --- |
| Component Name | The component (OpenHA / OpenProxy / OpenBackup) to which the log file belongs |
| File Name | The name of the original log file generated by the component (e.g., `patroni.log`) |
| Last Updated | The last modified time of the log file (yyyy.mm.dd HH\:mm:ss) |
| File Size (MB) | The size of the log file |

{% hint style="info" %}
**Note**

The log file composition for each component is as follows.

- **OpenBackup**: One log file is generated per DB Service.
- **OpenProxy**: One log file is generated for each instance where OpenProxy is installed, and files for instances where it is not installed are not displayed in the list.
- **OpenHA**: One log file is generated per instance.
{% endhint %}

You can use the component name filter (All / OpenHA / OpenProxy / OpenBackup) to display only the files of a specific component. Clicking a column header lets you change the sort criteria; the default is by last updated, newest first.

1. **On the Monitoring > Log Monitoring > Syslog**Click.
2. **Component** Click the tab.
3. Select the component name filter to narrow the list.
4. Check the name, update time, and size of the log files in the list.

## Component Log Download <a href="#download-component-logs" id="download-component-logs"></a>

{% hint style="info" %}
**Note**

For component log download, in the **OpenSQL**can only be used.
{% endhint %}

**Component** tab, select log files and then click the **Download** button to display a confirmation modal. The modal content and download method vary depending on the number of selected files.

<table><thead><tr><th>Number of Selected Files</th><th>Download Method</th><th>Modal Display Information</th></tr></thead><tbody><tr><td>1 file</td><td>Single file download with the original file name as is</td><td><ul><li>Component Name</li><li>File Name</li><li>Last Updated</li><li>File Size (MB)</li></ul></td></tr><tr><td>2 or more files</td><td><code>component_syslog_yymmdd.zip</code> Download as a ZIP file in the format</td><td><ul><li>Number of Selected Files</li><li>Download File Name</li></ul></td></tr></tbody></table>

The `yymmdd`in the ZIP file name refers to the date the download was requested.

When the download is complete, the result is announced via a toast message.

- **Success**: Displays "The Syslog file has been downloaded."
- **Failure**: Displays "Failed to download the Syslog file. Please try again."

1. **On the Monitoring > Log Monitoring > Syslog**Click.
2. **Component** Click the tab.
3. Select one or more log files to download.
4. **Download** Click the button.
5. Check the file information in the modal and **Download** Click the button.
