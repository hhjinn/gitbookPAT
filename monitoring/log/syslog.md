On the Syslog page, you can view system logs such as events, warnings, and errors that occur in the DB instance. Tibero lets you check the raw logs in the DB tab, while OpenSQL supports viewing and downloading the log file lists of the OpenHA, OpenProxy, and OpenBackup components through the Component tab in addition to the DB tab.

## View DB Syslog <a href="#view-db-syslog" id="view-db-syslog"></a>

On the **Monitoring > Log Monitoring > Syslog** page, you can check system logs such as events, warnings, and errors that occur in the system. When you enter the page, the DB tab is activated by default, and logs are displayed line by line. A line number is shown on the left of each row, and the raw log appears as is in the body area.

{% hint style="info" %}
**Note**

DB Syslog can only query data from within the last 7 days. Logs older than 7 days are not displayed.
{% endhint %}

{% hint style="info" %}
**Note**

For an OpenSQL DB Service added through registration, if `DB_LOG_DIR` in the `owl.env` used during initial registration was not set to the OpenSQL DB log folder, DB Syslog may not work properly. For details, see the [registration manual](../../installation-guide/database-server/opensql/register-db-prerequisites.md).
{% endhint %}

{% hint style="warning" %}
**Caution**

If the DB Service is in the `Terminating` state, you cannot query Syslog. A notice banner is displayed at the top of the screen.
{% endhint %}

1. Click **Monitoring > Log Monitoring > Syslog**.
2. Select the desired period from the query period dropdown.
3. **[OpenSQL]** Select the log type to check from the log level dropdown.
4. Enter a search term as needed.
5. Change the sort order as needed.
6. Check the log content in the list.
7. To refresh with the latest data, click the refresh icon.

## View component log list <a href="#component-log-list" id="component-log-list"></a>

{% hint style="info" %}
**Note**

Component log viewing is available only for **OpenSQL**. In Tibero, the **Component** tab is not displayed.
{% endhint %}

For an OpenSQL DB Service, you can view the log file lists of the OpenHA, OpenProxy, and OpenBackup components in the **Component** tab of the Syslog page.

| Item | Description |
| --- | --- |
| Component name | The component the log file belongs to (OpenHA / OpenProxy / OpenBackup) |
| File name | The name of the original log file generated by the component (e.g., `patroni.log`) |
| Last updated date and time | The last modified time of the log file (yyyy.mm.dd HH\:mm:ss) |
| File size (MB) | The size of the log file |

{% hint style="info" %}
**Note**

The log file configuration for each component is as follows.

- **OpenBackup**: One log file is generated per DB Service.
- **OpenProxy**: One log file is generated per instance where OpenProxy is installed, and files for instances without it are not shown in the list.
- **OpenHA**: One log file is generated per instance.
{% endhint %}

Using the component name filter (All / OpenHA / OpenProxy / OpenBackup), you can display only the files of a specific component. Clicking a column header lets you change the sort criteria; the default is the last updated date and time in descending order.

1. Click **Monitoring > Log Monitoring > Syslog**.
2. Click the **Component** tab.
3. Select the component name filter to narrow down the list.
4. Check the name, update date and time, and size of the log file in the list.

## Download component logs <a href="#download-component-logs" id="download-component-logs"></a>

{% hint style="info" %}
**Note**

Component log download is available only for **OpenSQL**.
{% endhint %}

When you select a log file in the **Component** tab and click the **Download** button, a confirmation modal appears. The modal content and download method vary depending on the number of files selected.

<table><thead><tr><th>Number of selected files</th><th>Download method</th><th>Information shown in the modal</th></tr></thead><tbody><tr><td>1 file</td><td>Downloaded as a single file with the original file name</td><td><ul><li>Component name</li><li>File name</li><li>Last updated date and time</li><li>File size (MB)</li></ul></td></tr><tr><td>2 or more files</td><td>Downloaded as a ZIP file in the format <code>component_syslog_yymmdd.zip</code></td><td><ul><li>Number of selected files</li><li>Download file name</li></ul></td></tr></tbody></table>

The `yymmdd` in the ZIP file name refers to the date the download was requested.

When the download is complete, the result is announced via a toast message.

- **Success**: Displays "The Syslog file has been downloaded."
- **Failure**: Displays "Failed to download the Syslog file. Please try again."

1. Click **Monitoring > Log Monitoring > Syslog**.
2. Click the **Component** tab.
3. Select one or more log files to download.
4. Click the **Download** button.
5. Check the file information in the modal and click the **Download** button.
