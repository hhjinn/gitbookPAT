On the Syslog page, you view system logs such as events, warnings, and errors occurring in DB instances. Tibero lets you check the raw logs in the DB tab, while OpenSQL additionally supports, through the Component tab beyond the DB tab, viewing and downloading the log file lists of the OpenHA, OpenProxy, and OpenBackup components.

## View DB Syslog <a href="#view-db-syslog" id="view-db-syslog"></a>

On the **Monitoring > Log Monitoring > Syslog** page, you check system logs such as events, warnings, and errors occurring in the system. When you enter the page, the DB tab is activated by default, and logs are displayed line by line. A row number is displayed on the left of each row, and the raw log appears as is in the body area.

{% hint style="info" %}
**Note**

DB Syslog only lets you view data from within the last 7 days. Logs older than 7 days are not displayed.
{% endhint %}

{% hint style="warning" %}
**Caution**

If the DB Service is in the `Terminating` state, you cannot view the Syslog. An informational banner is displayed at the top of the screen.
{% endhint %}

1. Click **Monitoring > Log Monitoring > Syslog**.
2. Select the desired period from the query period dropdown.
3. **[OpenSQL]** Select the log type to check from the log level dropdown.
4. Enter a search term as needed.
5. Change the sort order as needed.
6. Check the log content in the list.
7. To refresh with the latest data, click the refresh icon.

## View component log list <a href="#component-log-list" id="component-log-list"></a>

{% hint style="info" %}
**Note**

Component log viewing is available only in **OpenSQL**. In Tibero, the **Component** tab is not displayed.
{% endhint %}

In an OpenSQL DB Service, you view the log file lists of the OpenHA, OpenProxy, and OpenBackup components in the **Component** tab of the Syslog page.

| Item | Description |
| --- | --- |
| Component name | Component to which the log file belongs (OpenHA / OpenProxy / OpenBackup) |
| File name | Original log file name generated by the component (e.g., `patroni.log`) |
| Last update time | Last modified time of the log file (yyyy.mm.dd HH\:1f1f2-1f1f2:ss) |
| File size (MB) | Size of the log file |

{% hint style="info" %}
**Note**

The log file configuration by component is as follows.

- **OpenBackup**: One log file is created per DB Service.
- **OpenProxy**: One log file is created for each instance where OpenProxy is installed, and files for instances without it installed are not shown in the list.
- **OpenHA**: One log file is created per instance.
{% endhint %}

You can display only the files of a specific component using the component name filter (All / OpenHA / OpenProxy / OpenBackup). Clicking a column header changes the sort criteria, and the default is most recent by last update time.

1. Click **Monitoring > Log Monitoring > Syslog**.
2. Click the **Component** tab.
3. Select a component name filter to narrow down the list.
4. Check the name, update time, and size of the log file in the list.

## Download Component Logs <a href="#download-component-logs" id="download-component-logs"></a>

{% hint style="info" %}
**Note**

Component log download is available only in **OpenSQL**.
{% endhint %}

When you select a log file in the **Component** tab and click the **Download** button, a confirmation modal appears. The modal content and download method vary depending on the number of selected files.

<table><thead><tr><th>Number of selected files</th><th>Download method</th><th>Modal display information</th></tr></thead><tbody><tr><td>1 file</td><td>Downloaded as a single file with the original file name</td><td><ul><li>Component name</li><li>File name</li><li>Last update time</li><li>File size (MB)</li></ul></td></tr><tr><td>2 or more</td><td>Downloaded as a ZIP file in the format <code>component_syslog_yymmdd.zip</code></td><td><ul><li>Number of selected files</li><li>Download file name</li></ul></td></tr></tbody></table>

The `yymmdd` in the ZIP file name refers to the date on which the download was requested.

When the download completes, the result is shown as a toast message.

- **Success**: Displays "The Syslog file has been downloaded."
- **Failure**: Displays "Failed to download the Syslog file. Please try again."

1. Click **Monitoring > Log Monitoring > Syslog**.
2. Click the **Component** tab.
3. Select one or more log files to download.
4. Click the **Download** button.
5. Check the file information in the modal and click the **Download** button.
