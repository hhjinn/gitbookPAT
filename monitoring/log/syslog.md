On the Syslog page, you can view system logs such as events, warnings, and errors occurring in the DB instance. For Tibero, you can check the raw logs in the DB tab, and OpenSQL additionally supports, through the Component tab beyond the DB tab, viewing and downloading the log file lists of the OpenHA, OpenProxy, and OpenBackup components.

## Viewing the DB Syslog <a href="#view-db-syslog" id="view-db-syslog"></a>

**Monitoring > Log Monitoring > Syslog** On this page, you can check system logs such as events, warnings, and errors occurring in the system. When you enter the page, the DB tab is activated by default, and logs are displayed line by line. A line number is shown on the left of each row, and the raw log is displayed as-is in the body area.

{% hint style="info" %}
**Note**

The DB Syslog can only query data from within the last 7 days. Logs older than 7 days are not displayed.
{% endhint %}

{% hint style="warning" %}
**Caution**

If the DB Service is in `Terminating` state, the Syslog cannot be queried. A notice banner is displayed at the top of the screen.
{% endhint %}

1. **Monitoring > Log Monitoring > Syslog**Click it.
2. Select the desired period from the query period dropdown.
3. **[OpenSQL]** In the log level dropdown, select the log type to check.
4. Enter a search term as needed.
5. Change the sort order as needed.
6. Check the log contents in the list.
7. To refresh with the latest data, click the refresh icon.

## Viewing the component log list <a href="#component-log-list" id="component-log-list"></a>

{% hint style="info" %}
**Note**

Component log viewing is **OpenSQL**available only in. For Tibero, the **Component** tab is not displayed.
{% endhint %}

In the OpenSQL DB Service, the **Component** tab on the Syslog page is where you view the log file lists of the OpenHA, OpenProxy, and OpenBackup components.

| Item | Description |
| --- | --- |
| Component name | The component the log file belongs to (OpenHA / OpenProxy / OpenBackup) |
| File name | The original log file name generated by the component (e.g., `patroni.log`) |
| Last update time | The last modification time of the log file (yyyy.mm.dd HH\:1f1f2-1f1f2:ss) |
| File size (MB) | The size of the log file |

{% hint style="info" %}
**Note**

The log file composition by component is as follows.

- **OpenBackup**: One log file is created per DB Service.
- **OpenProxy**: One log file is created per instance where OpenProxy is installed; files of instances without it installed are not shown in the list.
- **OpenHA**: One log file is created per instance.
{% endhint %}

Using the component name filter (All / OpenHA / OpenProxy / OpenBackup), you can show only the files of a specific component. Clicking a column header lets you change the sort criterion, with the default being last update time in descending order.

1. **Monitoring > Log Monitoring > Syslog**Click it.
2. **Component** Click the tab.
3. Select the component name filter to narrow down the list.
4. Check the name, update time, and size of the log file in the list.

## Downloading component logs <a href="#download-component-logs" id="download-component-logs"></a>

{% hint style="info" %}
**Note**

For component log download, **OpenSQL**can be used.
{% endhint %}

**Component** after selecting a log file in the tab, **Download** clicking the button brings up a confirmation modal. The modal content and download method differ depending on the number of selected files.

<table><thead><tr><th>Number of selected files</th><th>Download method</th><th>Modal display information</th></tr></thead><tbody><tr><td>1 file</td><td>Single file downloaded with the original file name as-is</td><td><ul><li>Component name</li><li>File name</li><li>Last update time</li><li>File size (MB)</li></ul></td></tr><tr><td>2 or more</td><td><code>component_syslog_yymmdd.zip</code> Downloaded as a ZIP file in the format</td><td><ul><li>Number of selected files</li><li>Download file name</li></ul></td></tr></tbody></table>

In the ZIP file name, `yymmdd`refers to the date on which the download was requested.

When the download completes, the result is shown via a toast message.

- **Success**Displays "The Syslog file has been downloaded."
- **Failure**Displays "Failed to download the Syslog file. Please try again."

1. **Monitoring > Log Monitoring > Syslog**Click it.
2. **Component** Click the tab.
3. Select one or more log files to download.
4. **Download** Click the button.
5. Check the file information in the modal, then **Download** Click the button.
