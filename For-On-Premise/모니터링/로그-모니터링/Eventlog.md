# Eventlog

Eventlog 페이지에서는 OwlDB가 정의한 규칙에 따라 발생한 이벤트 로그를 조회합니다.

**모니터링 > 로그 모니터링 > Eventlog** 메뉴에서 DB 서비스에 발생한 이벤트 로그를 조회합니다. 조회 기간과 필터를 조합해 원하는 이벤트만 추려볼 수 있으며, 결과는 수신일 최신순으로 표시됩니다.

{% hint style="warning" %}
**주의**
DB 서비스가 `Terminating` 상태이면 Eventlog를 조회할 수 없습니다. 화면 상단에 안내 배너가 표시됩니다.
{% endhint %}


1. **모니터링 > 로그 모니터링 > Eventlog** 메뉴를 클릭합니다.
2. 조회 기간을 선택합니다. 특정 구간을 지정하려면 **직접 입력**을 선택한 후 시작일과 종료일을 설정합니다.
3. 상태 또는 메시지 필터를 선택해 조회할 이벤트 유형을 좁힙니다.
4. 특정 메시지를 찾으려면 검색창에 키워드를 입력합니다.
5. 조회 결과에서 **DB 서비스** 또는 **인스턴스** 이름을 클릭해 해당 상세 페이지로 이동합니다.

메시지 컬럼에 표시되는 Eventlog 유형은 다음과 같습니다.

| 상태  | 발생 조건 | 메시지 |
|-----|-------|-----|
| Info | 인스턴스 상태 변경 | 인스턴스 상태가 {변경된 상태}로 변경되었습니다. ({상태 코드}) |
| Warning | CPU 사용량 50% 초과 | CPU 사용량 주의 수준(50%)를 초과했습니다. (현재 : {사용량}%) |
|     | Memory 사용량 50% 초과 | Memory 사용량 주의 수준(50%)를 초과했습니다. (현재 : {사용량}%) |
| Error | CPU 사용량 90% 초과 | CPU 사용량 경고 수준(90%)를 초과했습니다. (현재 : {사용량}%) |
|     | Memory 사용량 90% 초과 | Memory 사용량 경고 수준(90%)를 초과했습니다. (현재 : {사용량}%) |
