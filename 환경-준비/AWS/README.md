## 스토리지/디스크 유형

OwlDB는 데이터 저장 및 복구를 위해 다양한 스토리지 옵션을 제공합니다. 사용량, 성능, 데이터 복원력 등 필요에 따라 적합한 스토리지를 선택할 수 있습니다. 스토리지는 동적인 애플리케이션 요구 사항을 충족시키기 위해 쉽게 확장 가능하며, 데이터 백업 및 복구 기능도 제공합니다.

#### gp3

고성능 워크로드에 최적화된 SSD 기반 볼륨으로, 높은 IOPS와 낮은 대기시간을 제공합니다. 내구성이 뛰어나며, 용량 당 비용이 저렴합니다.

| Volume Size (GiB) | Volume IOPS (CNT) |
| ----------------- | ----------------- |
| 100 \~ 65,536     | 3,000 \~ 80,000   |

#### gp2

대량의 데이터를 저장하거나 처리하는 데 적합한 SSD 기반 볼륨으로, 용량 당 비용이 저렴합니다. 높은 IOPS를 제공하며 일관성이 다소 떨어질 수 있습니다. IOPS 값은 할당된 스토리지 크기에 따라 변경되며 사용자 설정이 불가합니다.

| Volume Size (GiB) | Volume IOPS (CNT) |
| ----------------- | ----------------- |
| 100 \~ 16,384     | 450 \~ 16,000     |

#### io2

매우 높은 IOPS와 일관된 성능을 제공하는 SSD 기반 볼륨으로, 내구성이 뛰어나며 용량 당 비용이 높습니다. 대기시간이 상대적으로 길다는 단점이 있습니다.

| Volume Size (GiB) | Volume IOPS (CNT) |
| ----------------- | ----------------- |
| 100 \~ 65,536     | 3,000 \~ 256,000  |

{% hint style="info" %}
**참고** Tibero TAC 토폴로지는 io2만 사용 가능합니다.
{% endhint %}
