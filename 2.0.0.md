> **Release Highlights**
> 
> - OpenSQL-based DB Service Support
> - Connection Information Management Feature
> - Data Space Management Feature
> - Unification of the Management Unit Name to 'DB Service'

# New Features

### OpenSQL Support

OwlDB now newly supports OpenSQL. You can build and manage the operation of OpenSQL DB Service from the same console as Tibero.



### Reapplying Parameter Modification History

You can select a previous setting from the past modification history and reapply it to the instance. Before applying, you can preview which values will change.



### Connection Information Management

**Endpoint Lookup**

You can view the connection address of the DB Service and the connection status of each node on a single screen.

**Access Control Management**

You can register the targets that can access the database and the authentication methods as rules. You can assign priorities to the rules to determine the order in which they are applied.

**OpenProxy Management**

You can view and modify connection pools, shards, connected users, and parameters. For modified parameters, you can preview the changes before applying them.

**Replication Slot Management**

You can create and delete replication slots. You can configure them to suit the replication target by specifying the slot type and retention scope.



### Data Space

**Data Space Management**

You can view and manage Tibero's tablespaces and data files as well as OpenSQL's databases on a single screen.

**Creating an OpenSQL Database**

You can directly create and delete databases within an OpenSQL DB Service. You can also check the active sessions and the last Vacuum execution time for each database.



### Monitoring

**Component Log Download**

For OpenSQL only, you can select and download log files by component. If you select multiple items, they are provided compressed as a ZIP file.

**Session Detail Lookup**

When you select a session from the list, you can view the service name, instance, status, elapsed time, and SQL ID in detail.

# **Changes**

## Feature Improvements

### **Backup/Recovery**

**Backup Interval Validation**

Validates that the Full Backup interval is not set shorter than the Incremental Backup interval.



### **Instance Monitoring**

**Monitoring Tab Layout Change**

The screen that used to list metrics has been reorganized into situation-based tabs, so you can immediately read what the current problem is.

- 'Quick Insight', 'Load', 'I/O', and 'Writes': These are divided by situation to show you what to look at right now.
- 'All': You can view all metrics as they are.



## Usability Improvements

### **General**

**Management Unit Name Change**

The management unit that was previously labeled 'Database' has been unified to 'DB Service'. The names used in screens and notifications have been changed accordingly.

**Screen Name Change**

The existing 'Backup Scheduler' has been changed to 'Backup Settings', and the existing 'Tablespace' has been changed to 'Data Space'.



### **Dashboard**

**Card Display Item Setting**

You can directly choose whether to display Cluster Info on the dashboard card. You can check the configured appearance in a preview.

**Card Status Information Added**

On the card, you can view data volume usage, an event log summary, and connection status together. DB Services that are being created are grouped together with their progress stage displayed.



### **Overview**

**Overview Tab Layout Change**

The 'Database' tab has been changed to 'Operation Info', and the 'Version' tab has been replaced with the 'Installation Info' tab, allowing you to check the installation configuration and applied patches together.
