> **Release Highlights**
> 
> - OpenSQL-based DB Service Support
> - Connection Information Management Feature
> - Data Space Management Feature
> - Unification of the Management Unit Name to 'DB Service'

# New Features

### OpenSQL Support

OwlDB now newly supports OpenSQL. You can build and operate OpenSQL DB Service management from the same console as Tibero.



### Reapplying Parameter Change History

You can select a previous configuration from the past change history and reapply it to the instance. Before applying, you can preview which values will change.



### Connection Information Management

**Endpoint Lookup**

You can check the connection address of the DB Service and the connection status of each node on a single screen.

**Access Control Management**

You can register the targets allowed to connect to the database and their authentication methods as rules. You can assign priorities to the rules to determine the order in which they are applied.

**OpenProxy Management**

You can view and modify connection pools, shards, connected users, and parameters. For modified parameters, you can preview the changes before applying them.

**Replication Slot Management**

You can create and delete replication slots. You can specify the slot type and retention scope to configure them according to the replication target.



### Data Space

**Data Space Management**

You can view and manage Tibero's tablespaces and data files along with OpenSQL's databases on a single screen.

**Creating an OpenSQL Database**

You can directly create and delete databases within an OpenSQL DB Service. You can also check the active sessions and the last Vacuum execution time for each database.



### Monitoring

**Component Log Download**

For OpenSQL only, you can select and download log files for each component. If you select multiple files, they are compressed and provided as a ZIP file.

**Session Detail Lookup**

When you select a session from the list, you can view the service name, instance, status, elapsed time, and SQL ID in detail.

# **Changes**

## Feature Improvements

### **Backup/Recovery**

**Backup Interval Validation**

Validates that the Full Backup interval is not set shorter than the Incremental Backup interval.



### **Instance Monitoring**

**Monitoring Tab Layout Changes**

The screen that previously listed metrics has been reorganized into context-based tabs, making it easy to immediately read what the problem is right now.

- 'Quick Insight', 'Load', 'I/O', and 'Writes': Divided by context to show what you need to look at right now.
- 'All': You can view all metrics as they are.



## Usability Improvements

### **General**

**Management Unit Name Change**

The management unit previously labeled as 'Database' has been unified to 'DB Service'. The name used in screens and notifications has been changed accordingly.

**Screen Name Changes**

The existing 'Backup Scheduler' has been changed to 'Backup Settings', and the existing 'Tablespace' has been changed to 'Data Space'.



### **Dashboard**

**Card Display Item Settings**

You can directly choose whether to display Cluster Info on the dashboard card. You can check the configured appearance in a preview.

**Card Status Information Added**

On the card, you can check data volume usage, event log summary, and connection status together. DB Services that are in the process of being created are grouped together with their progress stage displayed.



### **Overview**

**Overview Tab Layout Changes**

The 'Database' tab has been changed to 'Operation Info', and the 'Version' tab has been replaced with the 'Installation Info' tab, allowing you to check the installation configuration and applied patches together.
