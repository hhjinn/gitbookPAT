> **Release Highlights**
> 
> - OpenSQL-based DB Service Support
> - Connection Information Management Feature Provided
> - Data Space Management Feature Provided
> - Account Management and Approval Procedure Added

# New Features

### OpenSQL Support

OwlDB now newly supports OpenSQL. Deployment and operational management can be performed from the same console as Tibero, and OpenSQL is provided only in the Azure environment.



### Edition Selection

When creating a DB Service, you can select an edition that suits the scale of your usage.

- Standard Edition: Dedicated to single-server configurations, supporting up to 8 vCPUs.
- Enterprise Edition: Supports high availability and large-scale configurations, and can be used without vCPU limits.



### Reapplying Parameter Modification History

You can select a previous setting from the past modification history and reapply it to the instance. You can preview which values will change before applying.



### Connection Information Management

**Endpoint Lookup**

You can check the connection address of the DB Service and the connection status of each node on a single screen.

**Access Control Management**

You can register, as rules, the targets that can connect to the database and their authentication methods. You can assign priorities to rules to determine the order in which they are applied.

**OpenProxy Management**

You can view and modify connection pools, shards, connected users, and parameters. Modified parameters can be previewed before being applied.

**Replication Slot Management**

You can create and delete replication slots. You can configure them to suit the replication target by specifying the slot type and retention scope.

### 

### Data Space

**Data Space Management**

You can view and manage Tibero's tablespaces and data files as well as OpenSQL's databases on a single screen.

**OpenSQL Database Creation**

You can directly create and delete databases within an OpenSQL DB Service. You can also check the active sessions per database and the last Vacuum execution time.

### 

### Account Management

Administrators can create, modify, and delete user accounts, and check roles, permissions, and last access dates. Users without an account can request creation directly, and the account is activated after administrator approval.

### 

### Monitoring

**Component Log Download**

For OpenSQL only, you can select and download log files for each component. If multiple files are selected, they are compressed and provided as a ZIP file.

**Session Detail Lookup**

When you select a session from the list, you can check the service name, instance, status, elapsed time, and SQL ID in detail.

# **Changes**

## Feature Improvements

### **My Page**

**Improved Usage Status Lookup**

You can view usage history separately for Tibero and OpenSQL, and check detailed history directly from the list.



### **Instance Monitoring**

**Change of Monitoring Tab Configuration**

The screen that used to list metrics has been reorganized into situation-based tabs, so that you can immediately read what the problem is right now.

- 'Quick Insight', 'Load', 'I/O', and 'Writes': These are divided by situation to show you what you need to look at right now.
- 'All': You can check all metrics as they are.



## Convenience Improvements

### **General**

**Change of Management Unit Name**

The management unit previously labeled 'Database' has been unified as 'DB Service'. The name used across screens and notifications has been changed accordingly.

**Change of Screen Names**

The former 'Backup Scheduler' has been changed to 'Backup Settings', and the former 'Tablespace' has been changed to 'Data Space'.



### **Dashboard**

**Card Display Item Settings**

You can directly choose whether to display Cluster Info on dashboard cards. You can check the configured appearance via preview.

**Card Status Information Added**

On the card, you can check data volume usage, event log summary, and connection status together. DB Services that are currently being created are grouped together with their progress stages displayed.



### **Overview**

**Cluster Diagram Added**

On the Overview screen, you can check the cluster's node configuration and the connection status between nodes as a diagram.

**Change of Overview Tab Configuration**

The 'Database' tab has been changed to 'Operation Info', and the 'Version' tab has been replaced with the 'Installation Info' tab, allowing you to check the installation configuration and applied patches together.

**License Expiration Notice**

When the BYOL license expiration date approaches, the expected expiration date and renewal guidance are displayed on the Overview screen.
